# Medical Word Web Editor

A lightweight Word-like web editor for medical reports, built on **ASP.NET MVC 5 / .NET Framework 4.8**.

## Phase 1
- Rich-text editing (bold, italic, underline, font family/size, text/background color)
- RTL/LTR and alignment
- Tables
- DOCX import (text, common run formatting, tables, inline images)
- Extensible document-import architecture

> Legacy binary `.doc` import is intentionally separated behind an importer interface and will be added with a conversion provider in the next phase.
